# Roadmap v0.3.x: A Suíte de Containers (Carousel, Pager & TV)

Objetivo: Expandir o suporte da biblioteca para além de Listas e Grades, integrando Pagers, 
Carrosséis do Material 3 e containers otimizados para Android TV.

## v0.3.1: O Marco do Pager e Stepped Navigation [CONCLUÍDO]
*Foco: Transição entre itens individuais e saltos customizados.*
- [x] [State] Criar `CollectionPagerState`: Sincronizar `PagerState` com `CollectionState`.
- [x] [State] Implementar lógica de `step` (passo) universal para todos os layouts.
- [x] [UI] `CollectionPager`: Wrappers para `HorizontalPager` e `VerticalPager`.
- [x] [UI] `CollectionPagedPager`, `CollectionEdgedPager` e `CollectionSteppedPager`.
- [x] [UI] `CollectionSteppedList`, `CollectionSteppedGrid` e `CollectionSteppedStaggeredGrid`.
- [x] [UI] `CollectionDotIndicator`: Novo indicador visual de pontos (Sliding Window).
- [x] [UI] Refatorar `CollectionScaffold` para suporte a `BoxScope` e overlays.
- [x] [Test] 100% de cobertura nos novos componentes e lógica de step.
- [x] [App] Adicionar exemplos de Pager, Stepped Lists e Grids no Gallery App.

## v0.3.2: O Marco do Carrossel (Visual Showcase)
*Foco: Implementar os novos Carrosséis do Material 3 com telemetria.*
- [ ] `CollectionCarousel`: Baseado em `HorizontalMultiBrowseCarousel` e `HorizontalUncontainedCarousel`.
- [ ] Smart Snap: Integração com modos de animação `Snap` e `Elastic`.
- [ ] Adaptive Telemetry: Progresso de scroll para larguras dinâmicas.

## v0.3.3: O Marco da TV (Leanback Experience)
*Foco: Otimização para telas grandes e navegação via controle remoto.*
- [ ] `TvCollectionList/Grid`: Suporte a `androidx.tv.foundation.lazy`.
- [ ] Focus Management: Gerenciamento inteligente de foco para D-Pad.
- [ ] Featured Carousel: Componente de destaque imersivo para TV.
