# Roadmap 0.6.x: O Marco da navegação adaptativa (Adaptive Navigation)

Objetivo: Transformar o Composable Collections em um framework de containers de tela cheia, unindo a
gestão de coleções resilientes (v0.5.x) à navegação adaptativa inteligente para múltiplos form 
factors (Tablets, Dobráveis e Desktop).

## v0.6.0: O Marco da Modularidade (Splitting the Atom)
Foco: Organizar a biblioteca para suportar componentes adaptativos sem inflar o core.
- [ ] Módulo Adaptive: Criação do submódulo :adaptive para isolar dependências do Material3 Adaptive.
- [ ] Core Refactoring: Extração de interfaces de navegação genéricas para que listas possam se 
comunicar com qualquer Navigator.
- [ ] TV Stability: Consolidação da navegação por hardware (D-Pad) nos componentes de Grid existentes.

## v0.6.1: O Marco da Estrutura (The Brain Update)
Foco: Implementar o seu NavigableListDetailPaneScaffoldStateHolder como padrão de mercado.
- [ ] Adaptive Navigator: Integração oficial do NavigableListDetailPaneScaffoldStateHolder.
- [ ] Pane Management: Implementação de ShowDetailPane e ShowExtraPane com suporte nativo a 
animações de transição entre painéis.
- [ ] Window Size Synergy: Lógica automática para decidir quando mostrar painéis lado a lado ou em 
stack, baseada em WindowSizeClass.
- [ ] State Restoration: Garantir que o estado do Navigator e o scroll das coleções sobrevivam à 
morte do processo (Process Death).

## v0.6.2: O Marco da Sinergia (The Ecosystem Update)
Foco: Fazer com que as coleções e a navegação adaptativa trabalhem como uma única entidade.
- [ ] Collection-Pane Link: Extensões que permitem que um item de uma LazyCollection dispare 
automaticamente o navigateToDetailPane com tipagem segura.
- [ ] Structural Semantic: Suporte a acessibilidade aprimorada (TalkBack) para navegação entre 
painéis de lista e detalhe.
- [ ] Performance Elite: Otimização de recomposições para garantir que o painel de lista não sofra 
lag enquanto o painel de detalhe carrega dados pesados.
- [ ] Visual Samples: Criação de um app de demonstração mostrando um Dashboard adaptativo completo 
usando Lists, Grids e o seu novo Scaffold.
