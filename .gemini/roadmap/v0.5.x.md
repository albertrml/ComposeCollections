# Roadmap v0.5.x: O Marco da Resiliência (Response Integration)

Objetivo: Absorver a API Response e automatizar os estados da lista (Loading, Error, Success).

## v0.5.0: Fusão de APIs
- [ ] Integração do contrato `Response<T>` como dependência ou módulo `:collections-data`.
- [ ] Metadata Awareness: Lógica para ler `currentPage` e `hasMore` diretamente do objeto de resposta.

## v0.5.1: Auto-UI Containers
- [ ] `CollectionResponseContainer`: Componente que aceita um `Flow<Response<List<T>>>`.
- [ ] Auto-Shimmer: Renderização de esqueletos baseada no `LayoutSpec`.
- [ ] Empty & Error States: Telas padrão com botão de Retry integrado.

## v0.5.2: Smart Pagination
- [ ] Gatilhos Automáticos: Disparo de "carregar mais" baseado no estado do `Response`.
- [ ] Stale-While-Revalidate: Manter dados antigos na tela durante o refresh/loading.
