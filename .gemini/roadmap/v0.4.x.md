# v0.4.x: O Marco da Inteligência de Borda (Smart Search & Edge Discovery)
A versão 0.3.x transforma o ComposeCollections em uma camada de inteligência local. O foco deixa de 
ser apenas a "navegação por espaço" para se tornar "descoberta por significado", permitindo buscas 
instantâneas e saltos inteligentes entre dados em memória.

Metas Principais:
1. Zero Latency Discovery: Implementar um motor de busca local que maximiza o conjunto de dados 
atual em memória antes de exigir requisições ao banco de dados ou backend.
2. Precisão Semântica: Eliminar correspondências parciais indesejadas (ex: "Panela" ao buscar 
"Anel") através de filtragem por fronteira de palavra (word boundary).
3. Local Indexing (Edge Intelligence): Criar uma base de termos temporária e normalizada para 
garantir que buscas complexas em grandes listas (500+ itens) sejam executadas em milissegundos.
4. Navegação Híbrida: Permitir que os botões de navegação rápida (Forward/Backward) operem em modo 
"Smart", saltando apenas entre os itens que atendem ao critério de busca ativo.

Entregáveis Técnicos:
1. CollectionSearchManager (Módulo Ativo):
   - Novo componente desacoplado da UI que gerencia a lógica de filtragem.
   - Suporte a Tokens e Tags: Busca inteligente que cruza o nome do item com metadados/sinônimos (ex: "Aliança" associada à tag "anel").
   - Lazy Indexing: Processamento em segundo plano do conjunto de dados atual para otimizar buscas subsequentes. 
2. Motor de Normalização (PT-BR)
   - Extensão String.normalizeForSearch(): Tratamento robusto de acentos, cedilha, caracteres especiais e case-insensitivity.
   - Implementação de filtros via Regex de Fronteira para garantir que apenas palavras completas ou tokens válidos sejam correspondidos.
3. Smart Navigation API
   - Evolução do CollectionState para aceitar um MatchMap proveniente do SearchManager.
   - Comportamento de "Salto Inteligente": O scroll programático ignora itens irrelevantes, movendo-se diretamente para o próximo "match" no viewport.
4. Expansion Hooks (Ganchos de Expansão)
   - Callbacks para o desenvolvedor gerenciar o volume de dados:
     - onLocalResultsLow: Disparado quando a busca local retorna poucos itens, sinalizando a necessidade de buscar mais no backend/banco.
     - onQueryRefined: Evento para recalibrar a estratégia de busca conforme o usuário digita.
5. Reactive UI & Animations
   - Integração nativa com Modifier.animateItem(): Os itens restantes na lista deslizam suavemente para as novas posições após a filtragem.
   - Atualização dinâmica da telemetria: totalPages e currentPage passam a refletir o conjunto filtrado em tempo real.

Impacto na Experiência (UX/DX):
- Para o Usuário: Resposta visual instantânea ao digitar. A navegação rápida se torna uma ferramenta
de precisão para encontrar exatamente o que procura dentro do contexto carregado.
- Para o Desenvolvedor: Facilidade em implementar buscas robustas em grandes coleções sem se 
preocupar com a complexidade de algoritmos de normalização ou otimização de scroll.

## v0.4.0: O Alicerce (Normalização e Lógica Pura)
Foco: Ferramentas isoladas que não dependem da UI.
- Entregável 1: Extensão String.normalizeForSearch(). Implementação robusta para PT-BR (remoção de 
acentos, caracteres especiais, lowercase).
- Entregável 2: Motor de Predicados. Lógica de busca por tokens e Regex de Fronteira (\bterm\b) para 
evitar falsos positivos como "Panela".
- Entregável 3: Bateria de Testes Unitários. Garantir que a lógica de "Anel" vs "Aliança" vs 
"Panela" funcione perfeitamente no nível de código puro.

## v0.4.1: O Cérebro (CollectionSearchManager)
Foco: Gestão de dados em memória e Indexação.
- Entregável 1: Classe CollectionSearchManager. Um componente agnóstico de UI que mantém o estado da 
busca.
- Entregável 2: Lazy Indexing. Estratégia para processar os n itens (500 para efeito de exemplo) em 
segundo plano e criar um mapa de termos/tags otimizado.
- Entregável 3: API de Tags. Suporte para que objetos complexos forneçam metadados de busca 
(sinônimos).

## v0.4.2: Inteligência Visual (Reactive Filtering)
Foco: A lista começando a reagir ao Cérebro.
- Entregável 1: Integração do SearchManager com o CollectionList e CollectionGrid.
- Entregável 2: Animações de Layout. Implementação do Modifier.animateItem() para que os itens 
deslizem e sumam suavemente conforme o filtro é aplicado.
- Entregável 3: Telemetria Reativa. Atualização automática de totalPages e currentPage baseada 
apenas nos itens que "sobraram" no filtro.

## v0.4.3: Navegação Semântica (Smart Jumps)
Foco: Evolução dos botões de navegação rápida.
- Entregável 1: Modo Smart Navigation. Uma variante onde a lista continua completa, mas os botões 
"Forward" e "Backward" saltam apenas entre os itens que deram "match".
- Entregável 2: Telemetria de Resultado. O CollectionPageCounter passa a exibir: "Item X de Y 
encontrados".
- Entregável 3: Scroll de Precisão. Ajuste do motor de scroll para centralizar o item encontrado no 
viewport.

## v0.4.4: Inteligência de Borda (Edge Discovery Hooks)
Foco: Conexão com o mundo externo (Banco/Backend).
- Entregável 1: Expansion Hooks. Implementação dos callbacks onResultsThresholdReached (ex: disparar 
busca no banco quando houver menos de 5% dos resultados locais).
- Entregável 2: Gerenciador de Merge. Lógica para integrar novos dados vindos do banco à lista atual 
sem perder o contexto da busca.
- Entregável 3: Exemplo Completo de E-commerce. Um sample mostrando a transição suave entre busca 
local e busca remota.
